# api

Python scripts that gather TODO list data from a REST API.

- 0-gather_data_from_an_API.py: prints an employee's TODO progress
- 1-export_to_CSV.py: exports an employee's tasks to CSV
- 2-export_to_JSON.py: exports an employee's tasks to JSON
- 3-dictionary_of_list_of_dictionaries.py: exports all employees' tasks to JSON
